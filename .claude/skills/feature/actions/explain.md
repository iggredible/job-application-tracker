# Explain

1. Read `docs/features/current.md`.
2. Run `git diff main --name-only` to list the changed files.
3. For each file created or changed:
   - Show the path and whether it is new or modified
   - Explain in one or two sentences what it does or what changed
   - Name the key functions, classes or components
   - Where it helps, name the Ruby on Rails equivalent of the pattern
4. Show how one request flows through the new code, from the route or component down to the database and back.
5. State which parts are deterministic and which call the LLM.
6. End with three questions an interviewer might ask about this feature, each with a short answer.
